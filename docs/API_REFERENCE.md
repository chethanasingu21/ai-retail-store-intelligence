# API Reference

## Base URL

http://localhost:8000

---

# Health Check

## GET /health

Checks service availability.

### Response

```json
{
  "status": "healthy"
}
```

---

# Event Ingestion

## POST /events/ingest

Ingests retail events generated by the AI pipeline.

### Request

```json
{
  "events": [
    {
      "event_id": "123",
      "store_id": "purplle_001",
      "visitor_id": "visitor_001",
      "camera_id": "cam1",
      "event_type": "zone_visit",
      "timestamp": "2026-05-30T10:00:00",
      "metadata": {
        "zone": "skincare"
      }
    }
  ]
}
```

### Response

```json
{
  "accepted": 1,
  "rejected": 0
}
```

# Store Metrics

## GET /stores/{store_id}/metrics

Returns store-level metrics.

### Example

GET /stores/purplle_001/metrics

### Response

```json
{
  "store_id": "purplle_001",
  "footfall": 317,
  "unique_visitors": 142,
  "visitors_inside": 142
}
```

---

# Funnel Analytics

## GET /stores/{store_id}/funnel

Returns customer funnel statistics.

### Example

GET /stores/purplle_001/funnel

### Response

```json
{
  "store_id": "purplle_001",
  "entered": 100,
  "engaged": 80,
  "checkout": 50,
  "purchased": 30
}
```

---

# Heatmap Analytics

## GET /stores/{store_id}/heatmap

Returns zone popularity information.

### Example

GET /stores/purplle_001/heatmap

### Response

```json
{
  "store_id": "purplle_001",
  "zones": {
    "skincare": 140,
    "makeup": 108
  }
}
```

---

# Anomaly Detection

## GET /stores/{store_id}/anomalies

Returns detected operational anomalies.

### Example

GET /stores/purplle_001/anomalies

### Response

```json
{
  "store_id": "purplle_001",
  "anomalies": [
    {
      "type": "QUEUE_SPIKE",
      "severity": "INFO",
      "message": "High visitor volume detected"
    }
  ]
}
```
