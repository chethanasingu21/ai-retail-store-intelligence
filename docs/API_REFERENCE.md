# API Reference

## Overview

The Store Intelligence Platform exposes REST APIs for ingesting retail events and generating business intelligence insights from customer behavior and sales data.

## Production URL

API Base URL:

https://ai-retail-store-intelligence.onrender.com

Swagger Documentation:

https://ai-retail-store-intelligence.onrender.com/docs

Health Endpoint:

https://ai-retail-store-intelligence.onrender.com/health

# Event Ingestion

## POST /events/ingest

Accepts retail events generated by the AI detection pipeline.

### Request

```json
{
  "events": [
    {
      "event_id": "e1",
      "store_id": "purplle_001",
      "visitor_id": "v1",
      "camera_id": "cam1",
      "event_type": "person_entered",
      "timestamp": "2026-06-03T10:00:00Z",
      "metadata": {
        "zone": "entrance"
      }
    }
  ]
}
```

### Response

```json
{
  "accepted": 1,
  "rejected": 0
}
```

# Store Metrics

## GET /stores/{store_id}/metrics

Returns overall store traffic metrics.

### Example

GET /stores/purplle_001/metrics

### Response

```json
{
  "store_id": "purplle_001",
  "footfall": 3,
  "unique_visitors": 3,
  "visitors_inside": 3
}
```

### Metrics Definitions

| Metric          | Description                |
| --------------- | -------------------------- |
| footfall        | Total customer entries     |
| unique_visitors | Distinct visitors detected |
| visitors_inside | Current visitor count      |

---

# Customer Funnel Analytics

## GET /stores/{store_id}/funnel

Returns customer journey funnel statistics.

### Example

GET /stores/purplle_001/funnel

### Response

```json
{
  "store_id": "purplle_001",
  "entered": 3,
  "engaged": 1,
  "checkout": 1,
  "purchased": 1
}
```

### Funnel Stages

| Stage     | Description                        |
| --------- | ---------------------------------- |
| entered   | Visitors entering the store        |
| engaged   | Visitors interacting with products |
| checkout  | Visitors reaching checkout         |
| purchased | Completed purchases                |

# Supported Event Types

The platform currently supports the following event types:

| Event Type         | Description                      |
| ------------------ | -------------------------------- |
| person_entered     | Visitor enters the store         |
| product_engaged    | Visitor interacts with a product |
| checkout_visit     | Visitor reaches checkout         |
| purchase_completed | Visitor completes a purchase     |

# Error Responses

## 400 Bad Request

```json
{
  "detail": "Invalid request"
}
```

## 404 Not Found

```json
{
  "detail": "Store not found"
}
```

## 422 Validation Error

```json
{
  "detail": [
    {
      "loc": ["body"],
      "msg": "Validation error",
      "type": "value_error"
    }
  ]
}
```

## 500 Internal Server Error

```json
{
  "detail": "Internal server error"
}
```
